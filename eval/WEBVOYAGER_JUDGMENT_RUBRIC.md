# WebVoyager Judgment Rubric

Apply this rubric before looking at aggregate scores. Judge each repeat independently from its
answer and recorded evidence.

- **Pass:** every requested condition is answered specifically and supported by the run evidence.
- **Fail:** the answer is wrong, incomplete, unsupported, or the run did not complete.
- **Uncertain:** live-site ambiguity prevents a defensible pass/fail decision. Do not use uncertain
  merely because the answer is hard to inspect.
- A verifier-accepted `done` is not automatically a pass.
- Navigation labels, headings, and product categories are not concrete methods/options unless the
  page explicitly defines them that way.
- For count/list tasks, enumerate distinct visible items first and require the numeric count to
  match. Separately offered variants count separately unless the task asks for product families.
- Relative dates such as “yesterday” pass only when visibly shown and captured on the run date.
- Use the same interpretation across all repeats. For Apple--6, separately offered AirPods 4 and
  AirPods 4 ANC variants are distinct.
